## 3. 纤维×基体组合推荐参数

### CF+PLA（碳纤维增强PLA）— 最常用

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| extruder_temp | 210-230°C | PLA基础温度+10-20°C补偿纤维冷却 |
| bed_temp | 60°C | 标准PLA热床温度 |
| layer_height | 0.15-0.25mm | 细层高有助于纤维铺放精度 |
| first_layer_height | 0.2-0.3mm | 首层略厚增强附着力 |
| nozzle_d | 0.4-0.6mm | 建议≥0.4mm避免纤维堵塞 |
| filament_d | 1.75mm | 标准耗材直径 |
| offset | 0.6-0.8mm | 碳纤维偏移量较小 |
| reinforced_fiber_d | 1.0mm | 碳纤维束径 |
| base_fiber_d | 1.0mm | 基体纤维径 |
| speed | 30-60mm/s | 降速保证纤维铺放质量 |
| 铺设方式 | 轮廓增强 | 纤维沿轮廓方向铺设 |

## 4. 用途→材料推荐映射

| 用户描述的用途 | 推荐纤维 | 推荐基体 | 原因 |
|----------------|----------|----------|------|
| 高强度、结构件、承重 | 碳纤维CF | PA或PETG | CF最高强度 |
| 轻量化、减重 | 碳纤维CF | PLA | CF密度最低 |
| 抗冲击、防震减振 | 芳纶KF | PLA或PETG | KF抗冲击性最佳 |
| 绝缘、电子设备外壳 | 玻璃纤维GF | PETG | GF绝缘性好 |
| 耐高温 | 玄武岩BF或CF | PA | BF耐600°C+ |
| 环保、可降解 | 天然纤维NF | PLA | NF+PLA全可降解 |
| 耐磨、滑动部件 | UHMWPE | PA | UHMWPE自润滑 |
| 性价比高 | 玻璃纤维GF | PLA | GF成本最低 |
| 最易打印 | 碳纤维CF | PLA | CF+PLA工艺最成熟 |

## 5. 参数关联规则

1. **层高 vs 喷嘴直径**：`layer_height` ≤ `nozzle_d` × 0.75（经验公式）
2. **偏移量 vs 纤维类型**：
   - CF: offset ≈ 0.6-0.8mm（纤维束细）
   - GF: offset ≈ 0.8-1.2mm（纤维束粗）
   - KF: offset ≈ 0.7-1.0mm
3. **温度 vs 速度**：速度每增加20mm/s，温度需提高5-10°C
4. **首层高度**：`first_layer_height` ≥ `layer_height`（通常1.2-1.5倍）
5. **reinforced_fiber_d = base_fiber_d**：RF3D中两者通常相同
6. **碰撞距离**：`collision_dist_xy` 默认30mm，`collision_dist_z` 默认3000mm（大值=无Z碰撞约束）
7. **打印中心偏移**：GCode生成时默认中心(x0=150, y0=150)
