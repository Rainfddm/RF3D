## Core Capabilities

### 1. 材料与工艺参数知识库

加载 `references/material_params.md` 获取完整的材料参数知识库，包含：

- **6种纤维材料**：碳纤维(CF)、玻璃纤维(GF)、芳纶纤维(KF)、玄武岩纤维(BF)、天然纤维(NF)、超高分子量聚乙烯纤维(UHMWPE)
- **4种基体材料**：PLA、PETG、ABS、PA(尼龙)
- **每种组合的推荐参数**：喷嘴温度、热床温度、打印速度、层高范围、偏移量
- **参数关联规则**：如层高与喷嘴直径的关系、温度与速度的权衡

**使用方式**：当用户提到材料名称、用途场景或需要参数推荐时，查询知识库给出精确建议。

**示例**：
- 用户说"碳纤维增强" → 查询 CF+PLA 组合参数，推荐温度210-230°C
- 用户说"高强度零件" → 推荐 CF+PA 组合，温度260-280°C
- 用户说"我要打印耐高温的" → 推荐 CF+PETG 或 GF+ABS

### 2. 智能参数推荐与推理

根据用户模糊描述自动推断完整参数集，不需要用户逐项指定。

**推理链**：
1. 从用途/材料关键词推断纤维类型和基体类型
2. 从纤维类型推断 reinforced_fiber_d 和 base_fiber_d
3. 从基体类型推断温度范围
4. 从模型特征推断层高和偏移量
5. 校验所有参数关联约束

**参数关联约束**（必须遵守）：
- `first_layer_height` ≥ `layer_height`（首层通常略厚于其他层）
- `offset` ≈ `nozzle_d` × 2（偏移量约等于2倍喷嘴直径）
- `reinforced_fiber_d` 通常 = `base_fiber_d`
- 碳纤维偏移量通常 0.6-0.8mm，玻璃纤维 0.8-1.2mm
- 打印速度与温度正相关：速度越高，温度需适当提高

### 3. NLP→操作序列转换

将用户自然语言转换为标准 JSON 操作序列，通过 Flask API `/ai-terminal` 或 `CommandExecutor` 执行。

**可用命令及参数**：

| 命令 | 必需参数 | 可选参数 | 前置条件 |
|------|----------|----------|----------|
| `load_model` | `file_path` | - | 无 |
| `slice` | `layer_height` | `first_layer_height`, `offset` | 模型已加载 |
| `generate_path` | - | `collision_dist_xy`, `collision_dist_z`, `offset` | 已完成切片 |
| `generate_gcode` | - | `speed`, `extruder_temp`, `bed_temp` | 已生成路径 |
| `set_params` | 任意参数键值对 | - | 无 |
| `print` | `gcode_file` | - | GCode已生成 |

**操作序列 JSON 格式**：
```json
{
  "operations": [
    {
      "command": "slice",
      "parameters": {"layer_height": 0.2, "first_layer_height": 0.3, "offset": 0.8},
      "description": "切片模型，层高0.2mm"
    }
  ]
}
```

**参数约束**（硬限制，超出自动裁剪）：

| 参数 | 最小值 | 最大值 | 默认值 | 单位 |
|------|--------|--------|--------|------|
| layer_height | 0.05 | 0.8 | 0.2 | mm |
| first_layer_height | 0.1 | 0.8 | 0.3 | mm |
| nozzle_d | 0.2 | 1.2 | 0.4 | mm |
| filament_d | 1.5 | 3.0 | 1.75 | mm |
| offset | 0.3 | 2.0 | 0.8 | mm |
| extruder_temp | 160 | 300 | 200 | °C |
| bed_temp | 0 | 120 | 60 | °C |
| speed | 10 | 300 | 60 | mm/s |
| reinforced_fiber_d | 0.5 | 2.0 | 1.0 | mm |
| base_fiber_d | 0.5 | 2.0 | 1.0 | mm |

### 4. 工艺模板与预设方案

针对常见场景提供预设工艺方案，避免每次从零配置。加载 `references/process_templates.md` 获取模板详情。

**内置模板**：
- **碳纤维增强结构件**：CF+PLA，0.2mm层高，0.8mm偏移，210°C
- **玻璃纤维增强壳体**：GF+PETG，0.25mm层高，1.0mm偏移，240°C
- **轻量化填充结构**：CF+PLA，0.15mm层高，0.6mm偏移，200°C
- **高强度承载件**：CF+PA，0.3mm层高，0.8mm偏移，270°C
- **防震减振件**：KF+TPU，0.2mm层高，1.0mm偏移，220°C

**使用方式**：当用户描述场景时匹配最接近的模板，提供参数作为起点，再按需微调。

### 5. 错误恢复与多轮对话

**错误诊断规则**：

| 错误信息 | 诊断 | 建议修正 |
|----------|------|----------|
| "请先加载STL模型文件" | 模型未加载 | 提示上传或指定模型路径 |
| "请先对模型进行切片" | 跳过切片步骤 | 自动补入 slice 操作 |
| "Pipeline 未初始化" | 切片数据丢失 | 重新执行切片 |
| "路径数据维度错误" | 路径生成异常 | 检查偏移量和碰撞参数 |
| "GCode生成失败" | 路径数据为空 | 检查路径生成是否成功 |
| API 速率限制 | LLM 调用频率过高 | 等待后重试，减少 max_tokens |

**多轮对话状态跟踪**：
- 记住当前已执行的步骤（load → slice → path → gcode）
- 记住当前参数值，支持增量修改（"温度降到190"只改温度，其他保持）
- 支持回退重做（"重新切片，层高改为0.15"）

### 6. 模型分析与打印预估

**模型信息提取**（通过 VTK 读取后分析）：
- 模型尺寸（X/Y/Z 边界框）
- 近似体积和表面积
- 预估切片层数 = (Z高度 - first_layer_height) / layer_height + 1
- 预估打印时间 ≈ 路径总长度 / 打印速度

**支撑分析提示**：
- 当模型有悬空结构时，提醒用户可能需要支撑
- 当模型底部面积较小时，建议增加 brim/raft

## API Integration

通过 Flask Web API 与 RF3D 后端交互，所有请求发送到 `http://localhost:5000`：

| 端点 | 方法 | 用途 |
|------|------|------|
| `/ai-terminal` | POST | 自然语言指令（核心入口） |
| `/upload-model` | POST | 上传STL模型 |
| `/list-models` | GET | 列出已上传模型 |
| `/run-slice` | POST | 执行切片 |
| `/run-path-generation` | POST | 执行路径生成 |
| `/generate-gcode` | POST | 生成GCode |

**请求格式示例**（`/ai-terminal`）：
```json
{"input": "帮我把模型切片，碳纤维增强，层高0.2mm"}
```

## 操作流程

### 标准完整工作流

1. **加载模型**：确认模型文件存在（`/list-models`），若不存在则提示上传（`/upload-model`）
2. **参数推理**：根据用户描述匹配材料知识库和工艺模板，生成完整参数集
3. **确认参数**：向用户展示推荐参数，确认后执行
4. **切片**：调用 slice 操作
5. **路径生成**：调用 generate_path 操作
6. **GCode生成**：调用 generate_gcode 操作
7. **结果汇总**：报告生成状态、GCode文件路径、预估信息

### 查询类工作流

1. 识别为查询意图
2. 查询 `references/material_params.md` 知识库
3. 直接返回答案，不调用后端

### 修正类工作流

1. 识别为修改意图
2. 提取需修改的参数
3. 保留未提及的参数不变
4. 重新执行受影响的后续步骤

## Important Rules

1. **参数必须合理**：所有参数必须满足约束范围和关联规则，超出范围自动裁剪并告知用户
2. **步骤不可跳过**：load → slice → generate_path → generate_gcode 顺序不可颠倒或跳过
3. **模型文件优先**：执行任何操作前，先检查是否已有加载的模型，否则提示上传
4. **温度与材料匹配**：不同材料组合温度差异大，不可混用（如PLA温度200°C用于PA会失败）
5. **偏移量是核心参数**：纤维增强打印中 offset 直接影响纤维铺设质量，必须根据纤维类型推荐
6. **错误必须诊断**：后端返回错误时，必须根据错误诊断规则给出具体建议，不能只转发错误信息
7. **多轮记忆**：记住当前会话中的模型状态和参数值，支持增量修改
