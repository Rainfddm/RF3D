Continuous Fiber Reinforced 3D Printing

RF3D — 把 STL 变成连续纤维增强的打印路径与 GCode

面向纤维增强熔融沉积制造（FDM）的工艺生成平台：自动完成切片、费马螺旋路径规划、 区域间空走策略与 GCode 输出。同一套算法内核同时驱动 Web 服务与 Qt 桌面端， 保证两端生成的 GCode 一致。

STL / OBJ→ 切片→ 费马螺旋路径→ 路径精简→ GCode

核心特性

都对应到可验证的代码路径，不是宣传语。

连续路径，减少空走

轮廓经等值线处理后用费马螺旋连接成连续路径 gen_fermat_curve，而非逐圈断开。

区域间空走不拉丝

按区域分块生成，块间发 G0 不挤出，并自动 回抽 → 空走 → 回填。

路径精简

Douglas-Peucker，阈值取 max(nozzle_d×0.4, layer_height)， 并保留几何关键点。

双端同一内核

Web 与桌面共用 Qt-free 的 PipelineExecutor， 同一模型输出一致。

AI 工艺助手

自然语言 → 结构化操作序列：材料识别、参数推荐、物理约束校验后再执行。

参数单一真相源

默认值只在 ProcessDecisionEngine.default_params 定义， Web 表单、桌面端初值、AI prompt 均由此渲染。

快速开始

四步，顺序固定。需要 Python 3.10+（在 3.11 上验证）。

  1. 安装依赖

    建议用独立虚拟环境。

    python -m venv .venv
# Windows: .venv\Scripts\activate
source .venv/bin/activate

pip install -r requirements.txt
  2. 配置环境变量

    模板里只有占位符，真实密钥只放本地 .env（已被 .gitignore 排除）。

    cp .env.example .env       # Windows: copy .env.example .env
  3. 初始化数据库

    创建 user 表。跳过这一步，注册/登录会报 no such table: user。

    python -m flask --app app db upgrade
  4. 启动

    默认 http://localhost:5000。

    python app.py              # Web
python -m suFabUI.main     # 桌面端
关于 src 布局：本项目 suFabEngine/ 与 suFabUI/ 使用 src/ 布局。发布包的 app.py 会自动把两个 src 目录加入 sys.path，因此不需要 pip install -e， 也不需要设置 PYTHONPATH。

使用方法

Web 界面

注册 → 上传模型 → 设参数 → 切片 → 生成路径 → 下载 GCode；也可在 AI 终端直接用一句话描述需求。

API 调用

路由方法说明
/upload-modelPOST上传模型（multipart），返回顶点/面片与 file_path
/run-slicePOST切片，返回真实层数 layers
/run-path-generationPOST生成路径，返回 point_count
/generate-gcodePOST生成 GCode，返回文件名与下载地址
/ai-terminalPOST自然语言 → 操作序列并执行
/api/register · /api/loginPOST账户与会话
/uploads/<path>GET下载生成的 GCode
/docsGET接口说明页

Python 直接调用引擎

from suFabEngine.pipeline_executor import PipelineExecutor

ex = PipelineExecutor()                     # 请求级实例，状态不跨请求共享
ex.execute_cmd("load_model", file_path="uploads/model.stl")
ex.execute_cmd("slice", layer_height=0.2, infill_density=30)
path   = ex.execute_cmd("generate_path")    # (N,3) numpy 数组
result = ex.execute_cmd("generate_gcode", speed=60, extruder_temp=200)
print(result["gcode_filename"], result["download_url"])

AI 终端

curl -X POST http://localhost:5000/ai-terminal \
     -H "Content-Type: application/json" \
     -d '{"input": "用碳纤维打印一个无人机螺旋桨，轻量化"}'

链路：材料/场景识别 → 参数推荐注入 prompt → LLM 输出操作序列 → 物理约束校验 → 逐条执行。

工艺参数默认值

定义在 suAgent/process_decision_engine.py，是全项目唯一真相源。

参数默认值含义
layer_height0.2层高 (mm)
first_layer_height0.2首层高度 (mm)
nozzle_d0.8喷嘴直径 (mm)
filament_d1.75耗材直径 (mm)
infill_density30.0填充密度 (%)
speed60打印速度 (mm/s)
extruder_temp200喷嘴温度 (°C)
bed_temp60热床温度 (°C)
offset0.8纤维沉积间距 (mm)

注意事项

以下都是当前版本的真实状态，不是待办清单的包装。

项现状
信用点体系 未强制 充值无凭证校验、扣减接口前端未调用，仅作界面展示
/uploads/<path> 无归属鉴权 知道文件名即可下载（文件名带 uuid 后缀降低可猜性）
桌面端长任务 主线程执行 切片与 GCode 生成会阻塞界面
错误状态码 路由级业务错误返回 HTTP 200，前端依据响应体 status 判断
3MF 格式 依赖 VTK 的 IO3MF 模块；pip 安装的 VTK 未编译该模块，上传 3MF 会返回 400，请用 STL/OBJ
GPU 路径优化 桌面端部分优化器使用 PyTorch 且调用 .cuda()，需要 NVIDIA GPU
平台验证 仅 Windows 验证 Linux / macOS 未实测
依赖版本 Flask 2.3.3 / Werkzeug 2.3.7 属较早版本，升级前需回归
首次部署必做：设置 FLASK_SECRET_KEY。 未设置时每个进程会随机生成密钥，多 worker 部署会导致登录随机失效。
